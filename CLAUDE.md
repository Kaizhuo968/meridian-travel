# CLAUDE.md

This project's rules for AI agents live in **[`AGENTS.md`](./AGENTS.md)** — read it first.

Quick reminders:

- **Never push to `main`.** Work on a branch named `agent/claude/<topic>` and open a PR.
- **Keep i18n in sync:** if you change copy, update **all 7 languages** in `i18n.js`.
- **Check RTL:** if you change layout or translations, verify Arabic (`ar`) still renders correctly.
- Run `node scripts/check.mjs` before committing.
- See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the full workflow.
